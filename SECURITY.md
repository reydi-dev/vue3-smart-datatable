# Security policy

No Vue 3 package has been published, and no release is currently supported.

Do not put credentials, personal data, or details of an unpatched vulnerability
in a public issue. To report a vulnerability privately, use GitHub private
vulnerability reporting if the repository offers it. If that option is absent,
open an issue asking the maintainer to enable a private reporting channel,
without including vulnerability details.

A version support policy will be added with the first release.
